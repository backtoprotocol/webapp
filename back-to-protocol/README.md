# Treehouse website

The public website for Treehouse, a personal identity vault from Back to Protocol.
The Next.js app introduces the product and explains how it fits into the company.

## Local development

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build and deploy

```bash
npm run build
npm run start
```

Cloudflare preview and deployment use `npm run preview` and `npm run deploy`.
The support form opens a prefilled message in the visitor’s email app; it does
not submit or store requests on the website.
